# Contrato da busca

**Implementado no Expert.** Fluxo: web `POST /api/search` com `{pergunta}` → rota Next.js envia ao backend o token interno e o e-mail da sessão no cabeçalho `X-User-Email` → backend `POST /api/search` (exige usuário autorizado com termo aceito, ver [acesso](../negocio/acesso.md#autorização-na-api)) → mock ou serviço de orquestração → classificação para o web. O backend limita pergunta a 1.000 caracteres. O resultado da API inclui `status`, `mensagem`, `cypher`, `avisos`, `colunas`, `linhas`, `truncado` e `tempoMs`.

Sem modelo disponível selecionado, o backend usa mock. Com modelo disponível, chama `POST /search` na orquestração com pergunta original, usuário, nome técnico e URL do modelo. Na rede Docker, usa `http://orchestration:8000` por padrão; `ORCHESTRATION_URL` apenas substitui esse endereço. O serviço responde com todas as chaves do contrato (`cypher`, `avisos`, `tokens_prompt`, `segundos`, `resultado`, `recusada`, `erro`), inclusive nas falhas do modelo/banco; transporte/HTTP inválido aciona a resposta simulada com aviso. O limite padrão devolvido pelo serviço é 50 linhas, máximo aceito 500.

Antes de executar Cypher gerado, Python e Quarkus conferem o tipo da consulta com `EXPLAIN` e só aceitam leitura; a transação de execução também é aberta em modo de leitura e tem timeout. A recusa é mostrada como `recusada`. Erro do modelo/serviço vira `indisponivel`; erro no Neo4j vira `erro_consulta`; resultado vazio ou só com células vazias vira `sem_resultado`.

O schema enviado ao modelo é o arquivo configurado em `CHATEAU_SCHEMA_ARQUIVO`, geralmente a fotografia [schema_producao.txt](../../chateau-expert/orchestration/schema/schema_producao.txt). Ele pode divergir do [modelo acadêmico rev_6](../modelo/grafo-academico.md). Não atribuir ao modelo capacidades ou entidades apenas porque existem no JSON Arrows.

**Evolução da issue #34 (decidida em 27/10, Expert `bc6f16a`, validação em produção pendente):** o navegador envia `{pergunta, modelName?}`, em que `modelName` é o nome técnico escolhido no seletor. O backend consulta o cadastro disponível para obter a URL e envia `modelo` e `ollama_url` à orquestração na mesma requisição. A URL não vem do navegador. Com um único modelo disponível, o seletor fica oculto e ele é enviado automaticamente; sem modelo disponível, a pergunta segue para o mock. [Análise](../../docs/analises/modelos-admin-2026-10-27.md).
